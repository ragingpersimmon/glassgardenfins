Privacy & Disclosure

How this static aquarium journal handles visitor data, product links, and advertising.

Privacy

Glass Garden Fins is a static GitHub Pages site. It has no accounts, forms, comments, backend database, or first-party analytics, and it does not directly collect or store personal information from visitors.

External services may receive ordinary request information when you use them. Google hosts the site’s web fonts, and Amazon receives information under its own privacy practices only when you choose to follow an Amazon product link.

Product-link disclosure

Amazon product links are currently ordinary, untagged links. Glass Garden Fins does not currently earn a commission from them.

If an Amazon Associates tracking ID is configured later, qualifying product links will be marked as sponsored and each page containing them will display this disclosure: “As an Amazon Associate, Glass Garden Fins earns from qualifying purchases.” A qualifying purchase may then earn the site a commission at no extra cost to the visitor.

Products are selected for relevance to the surrounding aquarium topic. A link is not a claim that a product will cure an animal, correct every water-quality issue, or suit every aquarium.

Advertising

Glass Garden Fins does not currently run AdSense or another advertising network. No advertising identifier has been configured, so there is no ads.txt authorization to publish at this time.

Security headers

The site uses a Content Security Policy in page metadata, but browser standards do not enforce framing controls such as frame-ancestors from a meta element. GitHub Pages does not provide custom response headers on this setup. Strong framing and transport headers would require placing a service such as Cloudflare in front of the current origin.
