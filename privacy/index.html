Privacy & Disclosure

Product links

Product links currently go straight to the manufacturer product pages. No affiliate links are live yet.

When affiliate links are turned on, this page and the relevant gear sections will say so clearly.

Analytics

Analytics scripts are only loaded when a measurement ID or analytics domain is configured in the site setup. In the default repository state, no analytics provider is active.

This setup supports a light-touch rollout so the site can stay fast while still being ready for traffic reporting later.

Search visibility

The site publishes a sitemap and robots file so it is ready to be submitted to search tools. Search-console verification can be added through the site configuration when the account token is available.
